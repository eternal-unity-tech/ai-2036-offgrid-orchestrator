# Skills Built Along the Way

This project maintains specialized agent skills that are created and extended as repositories are developed.

## Current Skills (local agent skills)

| Skill | Purpose |
|-------|---------|
| **offgrid-living-devices** | Master workflow for creating and managing the 50 device repositories under eternal-unity-tech |
| **mycelium-bio-materials** | Research data, species, design rules, and integration guidance for mycelium composites in devices and habitats |
| **edge-ai-device-control** | Ultra-low-power edge AI patterns, constraints, and control-loop design for personal living devices |

## Policy
Skills are created and refined *along the way* as new domains appear. When a recurring procedure or specialized knowledge set is needed, a new skill is initialized under the skill-creator process and kept lean and actionable.

These skills live in the agent environment and guide consistent development across all repositories.
